## 核心术语定义

### 「观之」

| 属性 | 说明 |
|------|------|
| **对外展示名** | 观之 |
| **内部技术模型** | Share |
| **定义** | 用户在地图上发布的社交媒体单位，包含图片/视频、位置、文字描述等 |

---

## 使用规范

### 1. UI 文案（用户可见层）

**必须使用「观之」**：
- 按钮文字：`发布观之`、`删除观之`
- 标题/提示：`暂无观之`、`这条观之`
- 错误信息：`无效的观之ID`
- 空态文案：`还没有观之`

**例外 - 保留「分享」（动词）**：
- 系统分享功能：`分享到微信`、`分享到朋友圈`
- 或使用「转发」替代

### 2. 代码注释/日志

**推荐写法**：
```swift
// 加载观之详情
// 删除观之成功
print("观之 \(shareId) 已加载")
```

**首次出现可加括号说明**：
```swift
// 观之（Share）列表刷新完成
```

### 3. 项目文档

**首次出现**：写「观之（内部模型 Share）」

**后续**：统一使用「观之」

### 4. 代码命名（禁止改动）

以下保持不变：
- Swift 类型名：`Share`、`ShareService`、`ShareDetailView`
- 变量名：`shareId`、`share`、`shares`
- API 路径：`/shares/`、`/share/{id}`
- JSON key：`share`、`shareId`
- 数据库表/字段：`share`

## 动词 vs 名词区分

| 类型 | 含义 | 使用术语 | 示例 |
|------|------|----------|------|
| **名词** | 用户发布的内容实体 | 观之 | "发一条观之"、"删除这条观之" |
| **动词** | 将内容分享到外部平台 | 分享/转发 | "分享到微信"、"转发给好友" |
