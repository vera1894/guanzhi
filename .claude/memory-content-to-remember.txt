## guanzhi 项目操作速记（跨端）

### 通用/术语/日志
- 先读 `projectBasicInfo/00_AGENT_RULES.md` + `01_PROJECT_OVERVIEW.md` + `04_TERMINOLOGY.md`
- UI 文案统一用「观之」，代码模型 `Share`，API/DB `share`，不要改类型/字段/路径
- 重大操作后在 `projectBasicInfo/logs/` 记录，命名 `YYYY-MM-DD-主题-角色.md`

### iOS 客户端
- 根目录 `guanzhi/`，打开 `guanzhi.xcworkspace`
- 时间处理：数组通常 UTC → `TimeZone(identifier: "UTC")`；字符串看后端 `@JsonFormat`（常见 Asia/Shanghai）；显示层用北京时间，参考 `NotificationDateHelper`
- 缓存：`Library/Caches/` 可能被系统清理，访问前 `fileExists`

### admin-web
- Node>=16，`npm run dev` / `npm run build`，产物 `admin-web/dist/`
- 关键：`src/views/`、`src/router/index.js`、`src/utils/request.js`、`vite.config.js`；默认后端 `http://localhost:8085`

## guanzhi 项目后端操作规则

### 任务专用文档索引

| 任务类型 | 必读文档 |
|----------|----------|
| 后端开发（写 Java 代码） | `Server/onettoo/重要项目信息/项目结构说明.md` |
| 后端部署（部署 JAR） | `projectBasicInfo/05_DEPLOYMENT_SSOT.md` + `02_CONNECTIONS.private.md` |
| 服务器操作 | `projectBasicInfo/99_SERVER_OPERATIONS_RULES.md` |

### 后端部署核心规则

1. **必须使用 systemd**：`systemctl restart onettoo`
2. **禁止使用**：`start.sh`、`pkill`、`nohup`
3. **SSM 命令**：用 `send-command` 而非 `start-session`
4. **S3 上传**：必须加 `--cli-read-timeout 300`
5. **文件传输**：presigned URL + curl 模式
6. **验收**：检查 `/version` 接口的 buildTime

### 目录结构

服务器使用 releases/current 架构：
- `/home/ec2-user/releases/vX.Y.Z/app.jar` - 版本目录
- `/home/ec2-user/current` - 软链接指向当前版本
- `/home/ec2-user/.env` - 环境变量（权限 600）

### 安全规则

- 禁止在文档中写密钥（DB_PWD、REDIS_PWD、JWT_SECRET）
- 密钥只存在于服务器 `.env` 文件
