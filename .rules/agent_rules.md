# Agent对话规则

1. 所有agent对话回复必须使用中文
2. 代码注释可以根据上下文使用中文或英文
3. 技术术语可以使用英文，但需要提供中文解释
4. 文件名和目录名保持原有的命名方式

# 重要文档说明

## PROJECT_SUMMARY.md - 项目概况文档
该文档包含项目的详细分析和架构说明，新agent应首先阅读此文档以了解：
- 项目的整体架构和设计模式
- 主要功能模块及其职责
- 数据流和状态管理方式
- 网络通信和API集成
- 数据存储方案
- UI/UX架构和组件组织
- 第三方库和依赖
- 项目的特殊功能

## CONTEXT_MANAGER.md - 上下文管理工具
该文档描述了如何使用上下文管理工具来维护项目状态：
- 如何更新项目状态信息
- 如何查看当前项目上下文
- 上下文信息包含的内容
- 如何使用自动化脚本

## PROJECT_CONTEXT.md - 项目当前状态
该文档包含项目的实时状态信息，包括：
- 最近的代码提交
- 当前开发状态
- 待解决的问题
- 近期开发计划

新agent在开始工作前应阅读PROJECT_SUMMARY.md了解项目概况，并检查PROJECT_CONTEXT.md了解项目的当前状态。
