# Assets - 图标资源

需要在此目录放置以下图标文件（PNG 格式）：

## TabBar 图标（81x81px 推荐）
- `tab-map.png` — 地图 tab 未选中图标
- `tab-map-active.png` — 地图 tab 选中图标
- `tab-list.png` — 发现 tab 未选中图标
- `tab-list-active.png` — 发现 tab 选中图标

## 地图标记
- `marker.png` — 地图上的标记点图标（36x36px）

## 应用图标
- `app-icon.png` — 观之 App 图标（用于引导下载栏，72x72px）

## 其他
- `icon-locate.png` — 定位按钮图标（44x44px）

注意：TabBar 图标建议提供 2x 和 3x 版本以适配高分辨率屏幕。
微信小程序 tabBar icon 推荐尺寸为 81x81px。
