## 一、距离校验服务（核心缺失）

### 1.1 创建 DistanceService

**文件路径**: `modules/service/DistanceService.java`

```java
package com.cloud.onettoo.modules.service;

import java.math.BigDecimal;

public interface DistanceService {
    /**
     * 计算两点之间的距离（米）
     * 使用 Haversine 公式
     */
    double calculateDistance(BigDecimal lat1, BigDecimal lon1, BigDecimal lat2, BigDecimal lon2);

    /**
     * 检查用户位置是否在分享位置的指定距离内
     */
    boolean isWithinRange(BigDecimal userLat, BigDecimal userLon,
                          BigDecimal shareLat, BigDecimal shareLon,
                          double maxDistanceMeters);
}
```

**实现类**: `modules/service/impl/DistanceServiceImpl.java`

```java
package com.cloud.onettoo.modules.service.impl;

import com.cloud.onettoo.modules.service.DistanceService;
import org.springframework.stereotype.Service;
import java.math.BigDecimal;

@Service
public class DistanceServiceImpl implements DistanceService {

    private static final double EARTH_RADIUS_METERS = 6371000;

    @Override
    public double calculateDistance(BigDecimal lat1, BigDecimal lon1,
                                    BigDecimal lat2, BigDecimal lon2) {
        double lat1Rad = Math.toRadians(lat1.doubleValue());
        double lat2Rad = Math.toRadians(lat2.doubleValue());
        double deltaLat = Math.toRadians(lat2.doubleValue() - lat1.doubleValue());
        double deltaLon = Math.toRadians(lon2.doubleValue() - lon1.doubleValue());

        double a = Math.sin(deltaLat / 2) * Math.sin(deltaLat / 2) +
                   Math.cos(lat1Rad) * Math.cos(lat2Rad) *
                   Math.sin(deltaLon / 2) * Math.sin(deltaLon / 2);
        double c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));

        return EARTH_RADIUS_METERS * c;
    }

    @Override
    public boolean isWithinRange(BigDecimal userLat, BigDecimal userLon,
                                 BigDecimal shareLat, BigDecimal shareLon,
                                 double maxDistanceMeters) {
        double distance = calculateDistance(userLat, userLon, shareLat, shareLon);
        return distance <= maxDistanceMeters;
    }
}
```

## 二、标签权限校验

### 2.1 创建 TagDefinitionService

**文件路径**: `modules/service/TagDefinitionService.java`

```java
package com.cloud.onettoo.modules.service;

import com.baomidou.mybatisplus.extension.service.IService;
import com.cloud.onettoo.modules.model.TagDefinitionDO;
import java.util.List;

public interface TagDefinitionService extends IService<TagDefinitionDO> {

    /**
     * 获取用户可贴的标签列表（根据等级）
     */
    List<TagDefinitionDO> getAvailableTagsForUser(Long userId);

    /**
     * 检查用户是否有权限贴指定标签
     */
    boolean canUserApplyTag(Long userId, String tagCode);

    /**
     * 检查用户今日贴标签次数是否超限
     */
    boolean hasReachedDailyTagLimit(Long userId);
}
```

**实现类**: `modules/service/impl/TagDefinitionServiceImpl.java`

```java
@Service
public class TagDefinitionServiceImpl extends ServiceImpl<TagDefinitionMapper, TagDefinitionDO>
        implements TagDefinitionService {

    @Autowired
    private UserService userService;
    @Autowired
    private LevelDefinitionService levelDefinitionService;
    @Autowired
    private ShareTagUserService shareTagUserService;

    @Override
    public List<TagDefinitionDO> getAvailableTagsForUser(Long userId) {
        UserDO user = userService.getById(userId);
        String userLevel = user.getLevelCode();

        // 获取用户等级的权重
        int userLevelWeight = getLevelWeight(userLevel);

        // 获取所有启用的标签
        List<TagDefinitionDO> allTags = this.lambdaQuery()
                .eq(TagDefinitionDO::getIsActive, 1)
                .orderByAsc(TagDefinitionDO::getSortOrder)
                .list();

        // 过滤出用户有权限贴的标签
        return allTags.stream()
                .filter(tag -> getLevelWeight(tag.getMinLevelCode()) <= userLevelWeight)
                .collect(Collectors.toList());
    }

    @Override
    public boolean canUserApplyTag(Long userId, String tagCode) {
        TagDefinitionDO tag = this.lambdaQuery()
                .eq(TagDefinitionDO::getTagCode, tagCode)
                .eq(TagDefinitionDO::getIsActive, 1)
                .one();

        if (tag == null) {
            return false;
        }

        UserDO user = userService.getById(userId);
        int userLevelWeight = getLevelWeight(user.getLevelCode());
        int requiredLevelWeight = getLevelWeight(tag.getMinLevelCode());

        return userLevelWeight >= requiredLevelWeight;
    }

    @Override
    public boolean hasReachedDailyTagLimit(Long userId) {
        UserDO user = userService.getById(userId);
        LevelDefinitionDO level = levelDefinitionService.lambdaQuery()
                .eq(LevelDefinitionDO::getLevelCode, user.getLevelCode())
                .one();

        if (level == null || level.getTaggingAllowance() == 0) {
            return true; // 没有贴标签权限
        }

        // 统计今日贴标签次数
        LocalDate today = LocalDate.now();
        long todayCount = shareTagUserService.lambdaQuery()
                .eq(ShareTagUserDO::getUserId, userId)
                .ge(ShareTagUserDO::getCreatedAt, today.atStartOfDay())
                .count();

        return todayCount >= level.getTaggingAllowance();
    }

    private int getLevelWeight(String levelCode) {
        switch (levelCode) {
            case "YOMIN": return 0;
            case "CHONGLANG": return 1;
            case "QIANSHUI": return 2;
            case "LANDONG": return 3;
            case "SHUIMU": return 4;
            case "DENGTA": return 5;
            default: return 0;
        }
    }
}
```

## 三、等级复合条件判断

### 3.1 修改 UserLevelServiceImpl

增加对"打卡某一标签的分享>100"等复合条件的支持：

```java
@Override
public String calculateLevel(Long userId) {
    UserDO user = userService.getById(userId);

    // 获取所有等级定义（按权重从高到低排序）
    List<LevelDefinitionDO> levels = levelDefinitionService.lambdaQuery()
            .orderByDesc(LevelDefinitionDO::getMinPoints)
            .list();

    for (LevelDefinitionDO level : levels) {
        if (meetsLevelRequirements(user, level)) {
            return level.getLevelCode();
        }
    }

    return "YOMIN"; // 默认等级
}

private boolean meetsLevelRequirements(UserDO user, LevelDefinitionDO level) {
    // 基础条件
    if (user.getPointsTotal() < level.getMinPoints()) return false;
    if (user.getCheckinCountTotal() < level.getMinCheckins()) return false;
    if (user.getCommentCountTotal() < level.getMinComments()) return false;

    // 额外条件（JSON格式）
    if (level.getExtraConditions() != null) {
        JSONObject extra = JSON.parseObject(level.getExtraConditions());

        // 检查"打卡任意标签的分享数"条件
        if (extra.containsKey("checkin_any_tag_min")) {
            int minCount = extra.getIntValue("checkin_any_tag_min");
            long maxTagCheckinCount = getMaxCheckinCountByTag(user.getId());
            if (maxTagCheckinCount < minCount) return false;
        }
    }

    return true;
}

/**
 * 获取用户打卡某一标签分享的最大次数
 */
private long getMaxCheckinCountByTag(Long userId) {
```

## 四、奖章条件动态判断

### 4.1 创建 MedalConditionEvaluator

```java
package com.cloud.onettoo.modules.service;

import com.alibaba.fastjson.JSONObject;
import com.cloud.onettoo.modules.model.MedalConditionDO;
import org.springframework.stereotype.Service;

@Service
public class MedalConditionEvaluator {

    @Autowired
    private ShareViewLogService viewLogService;
    @Autowired
    private ShareCheckinService checkinService;
    @Autowired
    private ShareTagUserService tagUserService;

    public boolean evaluate(Long userId, MedalConditionDO condition) {
        JSONObject params = JSON.parseObject(condition.getConditionParams());

        switch (condition.getConditionType()) {
            case "VIEW_SHARE_TOTAL":
                return evaluateViewShareTotal(userId, params);
            case "VIEW_SHARE_CONSECUTIVE":
                return evaluateViewShareConsecutive(userId, params);
            case "CHECKIN_TOTAL":
                return evaluateCheckinTotal(userId, params);
            case "CHECKIN_TAG":
                return evaluateCheckinTag(userId, params);
            case "SYSTEM_GRANT":
                return true; // 系统发放，直接通过
            default:
                return false;
        }
    }

    private boolean evaluateViewShareTotal(Long userId, JSONObject params) {
        int minCount = params.getIntValue("min_count");
        long actualCount = viewLogService.lambdaQuery()
                .eq(ShareViewLogDO::getUserId, userId)
                .count();
        return actualCount >= minCount;
    }

    private boolean evaluateCheckinTag(Long userId, JSONObject params) {
        String tagCode = params.getString("tag_code");
        int minCount = params.getIntValue("min_count");

        // 查询用户打卡的分享中，带有指定标签的数量
        long count = guanzhiMapper.countCheckinByTag(userId, tagCode);
        return count >= minCount;
    }

    // ... 其他条件判断方法
}
```
