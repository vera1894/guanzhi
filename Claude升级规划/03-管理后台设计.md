# 管理后台设计方案

本文档定义基于 Vue3 的管理后台设计，用于可视化管理系统配置和运营数据。

---

## 一、技术选型

| 组件 | 技术方案 | 说明 |
|------|---------|------|
| 前端框架 | Vue 3 + TypeScript | 最新的 Vue 版本 |
| UI 组件库 | Element Plus | 企业级后台组件库 |
| 构建工具 | Vite | 快速构建 |
| 状态管理 | Pinia | Vue 3 推荐 |
| 路由 | Vue Router 4 | |
| HTTP 客户端 | Axios | |
| 图表 | ECharts | 数据可视化 |
| 部署 | Nginx 静态托管 | 或集成到 Spring Boot |

### 2.2 页面功能详述

#### 2.2.1 数据大盘（Dashboard）

**展示内容**：
- 今日新增分享数 / 累计分享数
- 今日活跃用户数 / 累计用户数
- 今日打卡数 / 评论数 / 投票数
- 各等级用户分布（饼图）
- 最近 7 天活跃趋势（折线图）
- 待处理举报数（醒目提示）

**数据来源**：新增统计 API

```java
// AdminController.java 新增
@ApiOperation("获取大盘数据")
@GetMapping("/dashboard/stats")
public RestOut getDashboardStats() {
    Map<String, Object> stats = new HashMap<>();

    LocalDate today = LocalDate.now();

    // 今日新增分享
    stats.put("todayShares", guanzhiService.lambdaQuery()
            .ge(GuanzhiDO::getCreateDate, today.atStartOfDay())
            .count());

    // 今日活跃用户（有任何操作）
    stats.put("todayActiveUsers", calculateTodayActiveUsers());

    // 等级分布
    stats.put("levelDistribution", userService.getLevelDistribution());

    // 待处理举报
    stats.put("pendingReports", shareReportService.lambdaQuery()
            .eq(ShareReportDO::getStatus, 0)
            .count());

    return success(stats);
}
```

## 三、后端 API 补充

### 3.1 AdminController 扩展

```java
// ===== 标签配置管理 =====
@ApiOperation("获取所有标签定义")
@GetMapping("/config/tags")
public RestOut<List<TagDefinitionDO>> getAllTags() {
    return success(tagDefinitionService.list());
}

@ApiOperation("保存标签定义")
@PostMapping("/config/tag")
public RestOut saveTag(@RequestBody TagDefinitionDO tag) {
    tagDefinitionService.saveOrUpdate(tag);
    logOperation("TAG_UPDATE", "CONFIG", tag.getId(), null, tag);
    return success();
}

@ApiOperation("更新标签排序")
@PostMapping("/config/tags/sort")
public RestOut updateTagSort(@RequestBody List<Long> tagIds) {
    for (int i = 0; i < tagIds.size(); i++) {
        tagDefinitionService.lambdaUpdate()
                .eq(TagDefinitionDO::getId, tagIds.get(i))
                .set(TagDefinitionDO::getSortOrder, i)
                .update();
    }
    return success();
}

// ===== 褪色度配置管理 =====
@ApiOperation("获取褪色度配置")
@GetMapping("/config/fade")
public RestOut<Map<String, String>> getFadeConfig() {
    List<FadeConfigDO> configs = fadeConfigService.list();
    Map<String, String> result = configs.stream()
            .collect(Collectors.toMap(FadeConfigDO::getConfigKey, FadeConfigDO::getConfigValue));
    return success(result);
}

@ApiOperation("更新褪色度配置")
@PostMapping("/config/fade")
public RestOut updateFadeConfig(@RequestBody Map<String, String> configs) {
    for (Map.Entry<String, String> entry : configs.entrySet()) {
        fadeConfigService.lambdaUpdate()
                .eq(FadeConfigDO::getConfigKey, entry.getKey())
                .set(FadeConfigDO::getConfigValue, entry.getValue())
                .update();
    }
    logOperation("FADE_CONFIG_UPDATE", "CONFIG", null, null, configs);
    return success();
}

// ===== 举报管理 =====
@ApiOperation("获取举报列表")
@GetMapping("/reports")
public RestOut getReports(@RequestParam(defaultValue = "0") Integer status,
                          @RequestParam(defaultValue = "1") Integer page,
                          @RequestParam(defaultValue = "20") Integer size) {
    Page<ShareReportDO> pageResult = shareReportService.lambdaQuery()
            .eq(ShareReportDO::getStatus, status)
            .orderByDesc(ShareReportDO::getCreatedAt)
            .page(new Page<>(page, size));
    return success(pageResult);
}

@ApiOperation("处理举报")
@PostMapping("/report/handle")
public RestOut handleReport(@RequestBody HandleReportDTO dto) {
    ShareReportDO report = shareReportService.getById(dto.getReportId());
    if (report == null) {
        return failed("举报不存在");
    }

    report.setStatus(dto.getStatus()); // 1=确认违规, 2=驳回
    report.setHandlerId(SecurityUtils.getUserId());
    report.setHandleResult(dto.getResult());
    report.setHandledAt(new Date());
    shareReportService.updateById(report);

    if (dto.getStatus() == 1) { // 确认违规
        // 标记分享为违法
        GuanzhiDO share = guanzhiService.getById(report.getShareId());
        share.setStatus(3); // ILLEGAL
        guanzhiService.updateById(share);

        // 扣除作者积分
        userPointsService.addPoints(share.getUserId().longValue(), "ILLEGAL", share.getId());
    }

    logOperation("REPORT_HANDLE", "SHARE", report.getShareId(), null, dto);
    return success();
}

@ApiOperation("获取大盘数据")
@GetMapping("/dashboard/stats")
public RestOut getDashboardStats() {
    // ... 见上文

// ===== 操作日志 =====
@ApiOperation("获取操作日志")
@GetMapping("/logs")
public RestOut getOperationLogs(@RequestParam(defaultValue = "1") Integer page,
                                @RequestParam(defaultValue = "50") Integer size) {
    Page<AdminOperationLogDO> pageResult = operationLogService.lambdaQuery()
            .orderByDesc(AdminOperationLogDO::getCreatedAt)
            .page(new Page<>(page, size));
    return success(pageResult);

// ===== 辅助方法：记录操作日志 =====
private void logOperation(String operationType, String targetType, Long targetId,
                          Object beforeValue, Object afterValue) {
    AdminOperationLogDO log = new AdminOperationLogDO();
    log.setAdminId(SecurityUtils.getUserId());
    log.setOperationType(operationType);
    log.setTargetType(targetType);
    log.setTargetId(targetId);
    log.setBeforeValue(beforeValue != null ? JSON.toJSONString(beforeValue) : null);
    log.setAfterValue(afterValue != null ? JSON.toJSONString(afterValue) : null);
    operationLogService.save(log);
}
```

## 四、部署方案

### 4.1 独立部署（推荐）

```
                    ┌─────────────────┐
                    │     Nginx       │
                    │  (反向代理)      │
                    └────────┬────────┘
                             │
            ┌────────────────┼────────────────┐
            │                │                │
            ▼                ▼                ▼
    ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
    │  iOS App      │  │  Admin Web    │  │  Backend API  │
    │  /api/*       │  │  /admin/*     │  │  :8080        │
    └───────────────┘  └───────────────┘  └───────────────┘
```

**Nginx 配置示例**：
```nginx
server {
    listen 80;
    server_name admin.guanzhi.com;

    # 管理后台静态资源
    location / {
        root /var/www/guanzhi-admin/dist;
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://localhost:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
