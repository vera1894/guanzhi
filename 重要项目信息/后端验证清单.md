## 🐛 常见问题排查

### 问题 1：编译失败

**症状**：`mvn compile` 输出 `BUILD FAILURE`

**排查步骤**：
1. 检查是否有未导入的类
   ```bash
   grep -r "AdminOperationLogService" src/main/java/*/rest/AdminController.java
   ```
2. 检查新增文件是否在正确的包路径下
3. 清理并重新编译：`mvn clean compile`

### 问题 2：Bean 创建失败

**症状**：启动时报错 `Error creating bean`

**排查步骤**：
1. 检查 AdminOperationLogServiceImpl 是否有 `@Service` 注解
2. 检查 AdminOperationLogMapper 是否有 `@Mapper` 注解
3. 检查 Mapper XML 文件是否存在（如果使用 XML 配置）

### 问题 3：接口 404

**症状**：curl 访问返回 404

**排查步骤**：
1. 确认服务是否启动成功
2. 确认请求路径是否正确（/api/admin/fade/simulate）
3. 检查 AdminController 的 @RequestMapping 注解

### 问题 4：权限被拒绝

**症状**：使用 Admin Token 仍然返回 403

**排查步骤**：
1. 检查 Token 是否过期
2. 检查 JWT 中的 auth 字段是否包含 `ROLE_ADMIN`
   ```bash
   # 解码 JWT（使用在线工具或本地脚本）
   echo "token的payload部分" | base64 -d
   ```
3. 检查数据库中用户的 roles 字段
