### 关键文件说明

#### 1. 路由配置 (`src/router/index.js`)
```javascript
// 主要路由：
- /login                    # 登录页
- /                         # 主布局（需要登录）
  - /dashboard              # 仪表盘
  - /fade-simulation        # 褪色模拟器
  - /config/fade            # 褪色规则配置
  - /config/points          # 积分规则配置
  - /config/levels          # 等级定义管理
  - /config/tags            # 标签定义管理
```

#### 2. Axios封装 (`src/utils/request.js`)
```javascript
// 功能：
- baseURL配置（http://localhost:8085/api）
- 请求拦截器：自动添加Authorization Token
- 响应拦截器：统一错误处理（401跳转登录）
- 错误提示：Element Plus Message组件
```

#### 3. Vite配置 (`vite.config.js`)
```javascript
// 功能：
- 开发服务器配置（端口5173）
- API代理配置（/api → http://localhost:8085）
- Vue插件配置
- 开发工具配置
```

#### 4. 环境变量
```bash
# .env.development（开发环境）
VITE_API_BASE_URL=http://localhost:8085/api

# .env.production（生产环境）
```

#### 1. AdminController.java
```java
// 主要接口：
@GetMapping("/api/admin/config/fade-configs")        // 获取褪色配置列表
@PostMapping("/api/admin/config/fade-config")        // 保存褪色配置
@GetMapping("/api/admin/config/points-rules")        // 获取积分规则列表
@PostMapping("/api/admin/config/points-rule")        // 保存积分规则
@GetMapping("/api/admin/config/level-definitions")   // 获取等级定义列表
@PostMapping("/api/admin/config/level-definition")   // 保存等级定义
@GetMapping("/api/admin/config/tag-definitions")     // 获取标签定义列表
@PostMapping("/api/admin/config/tag-definition")     // 保存标签定义
@PostMapping("/api/admin/fade/simulate")             // 褪色曲线模拟（核心创新）

// 权限控制：
@PreAuthorize("hasAnyRole('ROLE_ADMIN')")           // 所有接口需要ADMIN角色
```

#### 2. AdminOperationLogService.java
```java
// 核心方法：
void recordChange(
    Long userId,          // 操作人ID
    String username,      // 操作人用户名

    String action,        // 操作类型（create/update/delete）
    Long recordId,        // 被操作记录的ID
    Object beforeValue,   // 修改前的值（自动转JSON）
    Object afterValue,    // 修改后的值（自动转JSON）
    String ipAddress      // 操作人IP
);
```

## 🔐 安全机制

### 1. JWT认证流程

```
┌──────────┐         ┌──────────┐         ┌──────────┐
│ 前端     │         │ 后端     │         │ 数据库   │
└────┬─────┘         └────┬─────┘         └────┬─────┘
     │                    │                    │
     │ 1. 登录请求        │                    │
     │ username/password  │                    │
     ├───────────────────→│                    │
     │                    │ 2. 验证用户        │
     │                    ├───────────────────→│
     │                    │ 3. 返回用户信息    │
     │                    │←───────────────────┤
     │                    │                    │
     │                    │ 4. 生成JWT Token   │
     │                    │ （包含user_id,     │
     │                    │  role等信息）      │
     │ 5. 返回Token       │                    │
     │←───────────────────┤                    │
     │                    │                    │
     │ 6. 存储Token到     │                    │
     │    localStorage    │                    │
     │                    │                    │
     │ 7. 后续API请求     │                    │
     │ (带Authorization)  │                    │
     ├───────────────────→│                    │
     │                    │ 8. 验证Token       │
     │                    │    解析权限        │
     │                    │                    │
     │                    │ 9. 检查ROLE_ADMIN  │
     │                    │                    │
     │ 10. 返回数据       │                    │
     │←───────────────────┤                    │
```

### 后端配置

#### application.yml
```yaml
spring:
  profiles:
    active: dev           # 激活的配置文件

  datasource:
    one:
      jdbc-url: jdbc:mysql://localhost:3306/ONETTOO
      username: root
      password: ""
      driver-class-name: com.mysql.cj.jdbc.Driver

  redis:
    host: localhost
    port: 6379

server:
  port: 8085

mybatis-plus:
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: com.example.onettoo.model

jwt:
  secret: [密钥]
  expiration: 86400       # Token过期时间（秒）
```
