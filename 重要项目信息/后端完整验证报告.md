**测试用例**:

**响应结果**:
```json
{
  "respCode": 0,
  "respMsg": "请求成功",
  "datas": {
    "currentFadeScore": 5,
    "estimatedFadeDays": 30,
    "timeline": [1, 3, 7, 15, 30, 60, 90],
    "fadeScores": [5, 15, 35, 75, 100, 100, 100],
    "dailyFadeIncrement": 5.0,
    "configInfo": "基础褪色: 6/天, 标签加成: -1.0/天, 总计: 5.0/天"
  }
}
```

**验证点**:
- ✅ 后端正确读取fade_config配置
- ✅ 计算逻辑正确：viewCount=50 → tier3 → 6/天
- ✅ 标签加成正确：2个标签 × (-0.5) = -1.0/天
- ✅ 总计正确：6 + (-1) = 5.0/天
- ✅ 时间轴数组格式正确，适合ECharts渲染
- ✅ 估算30天达到100分（100 ÷ 5 = 20天，但时间点[30]首次>=100）

**影响**: 不影响管理端验证，但前端登录可能需要调整
